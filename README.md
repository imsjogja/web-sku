## 🌐 Cara Menjalankan

### Opsi 1: Buka Langsung
```bash
open public/index.html
```

### Opsi 2: Local Server (Python)
```bash
cd public
python3 -m http.server 8000
# Buka http://localhost:8000
```

### Opsi 3: Local Server (PHP)
```bash
cd public
php -S localhost:8000
# Buka http://localhost:8000
```
